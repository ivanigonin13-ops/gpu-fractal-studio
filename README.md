# Интерактивный генератор фракталов на видеокарте (C++ / SFML)

Это программа, которая рисует на экране бесконечные математические узоры — фракталы (множества Мандельброта и Жюлиа). В них можно бесконечно приближать картинку, и внутри будут появляться новые, еще более сложные и красивые рисунки.

Главная фишка этого проекта — **скорость работы**. Вся тяжелая математика здесь перенесена с центрального процессора компьютера (CPU) на видеокарту (GPU). Благодаря этому картинка не виснет, а плавно выдает 60 кадров в секунду, как хорошая современная игра.

---

## 🛠 Простыми словами: почему это работает так быстро?

Обычно программы для расчета фракталов сильно нагружают компьютер. Если считать картинку на обычном процессоре, это похоже на то, как если бы вы заставили мощную легковую машину перевозить гору кирпичей: машина быстрая, но за раз может увезти всего пару штук (у процессора мало ядер, обычно от 4 до 16). Компьютеру приходилось каждую секунду гонять огромные массивы данных туда-сюда, из-за чего всё жутко лагало.

Я переписал этот алгоритм под видеокарту. Видеокарта — это как огромный автопарк из тысяч самосвалов. Её ядра гораздо проще, но их **несколько тысяч**. Видеокарта берет и считает каждый пиксель на экране одновременно. 

В итоге:
* **Процессор отдыхает:** Вентиляторы на компьютере не шумят, система не перегружена.
* **Видеокарта делает всю работу:** Картинка пересчитывается мгновенно, прямо внутри видеопамяти, без задержек.
* **Программа «весит» копейки:** Весь код для видеокарты вшит прямо внутрь программы. Ей не нужны никакие дополнительные папки и картинки, она запустится на любом компьютере.

## 🎮 Как этим управлять

Управление сделано максимально удобным и отзывчивым:

* **Клавиши `W`, `A`, `S`, `D`** — плавный полет по узорам (как в играх). Причем скорость умная: чем глубже вы залетаете внутрь фрактала, тем аккуратнее и плавнее становится шаг, чтобы не проскочить красивые места.
* **Колесико мыши** — приближение (зум). Программа приближает картинку именно туда, куда вы навели стрелку мыши (как на Яндекс или Гугл картах).
* **Стрелочка Вверх / Стрелочка Вниз** — регулировка четкости (детализации). Если сильно приблизиться и картинка размоется, нажмите стрелочку «Вверх», и видеокарта прорисует мельчайшие детали.
* **Пробел** — переключение режима. Переключает между классическим фракталом Мандельброта (похож на яблоко с узорами) и фракталом Жюлиа (похож на закрученные космические галактики).
* **Клавиша `R`** — изменить форму. Работает в режиме Жюлиа. Каждое нажатие выдает совершенно новый, уникальный случайный узор. Координаты красивых узоров программа пишет в терминал.
* **Клавиша `C`** — поменять цвета. Мгновенно перекрашивает фрактал в случайную новую цветовую палитру (неоновые, огненные, ледяные тона).

## 💻 Инструкция по установке и запуску

Программа написана на стандартном C++ и OpenGL, поэтому запустить её можно абсолютно везде. Выберите вашу операционную систему ниже.

---

### 1. Как запустить на Windows (Через VS Code и MinGW)

В Windows нет единого центра приложений для программистов, поэтому мы настроим всё вручную за 4 простых шага.

#### Шаг 1. Проверяем компилятор
У вас должен быть установлен компилятор GCC (MinGW). Чтобы проверить его наличие, откройте командную строку Windows (`cmd`) и введите:
```cmd
g++ --version
```
Если компьютер вывел текст с версией — всё отлично. Если пишет, что команда не найдена — установите пакет **MSYS2** (он ставит компилятор `g++` на Windows) и настройте его по любой базовой инструкции для VS Code.

#### Шаг 2. Скачиваем библиотеку SFML
1. Зайдите на официальный сайт [sfml-dev.org](https://sfml-dev.org) в раздел **Download** -> **SFML 2.6.x** (или 2.5.x).
2. Скачайте архив для вашего компилятора **MinGW** (например, `MinGW (SEH) - 64-bit`).
3. Распакуйте скачанный архив. Переименуйте получившуюся папку просто в `SFML` и положите её прямо на диск `C:\`.
4. *Проверка:* у вас должен получиться точный путь `C:\SFML\`, внутри которого лежат папки `include`, `lib` и `bin`.

#### Шаг 3. Собираем программу
Откройте в VS Code папку, где лежит ваш файл `main.cpp`. Откройте встроенный терминал и вставьте туда эту команду:
```cmd
g++ main.cpp -o fractal_studio.exe -I"C:\SFML\include" -L"C:\SFML\lib" -lsfml-graphics -lsfml-window -lsfml-system
```
*Что это значит:* флаг `-I` показывает компилятору, где искать настройки библиотеки, флаг `-L` — где лежит её бинарный код, а флаги `-l` в конце подключают графические модули. В папке появится файл `fractal_studio.exe`.

#### Шаг 4. Добавляем файлы запуска (Обязательно!)
Если запустить программу сейчас, Windows выдаст ошибку, что «отсутствуют файлы .dll». Исправляем это:
1. Зайдите в папку `C:\SFML\bin\`.
2. Выделите и скопируйте оттуда абсолютно все файлы с расширением **`.dll`**.
3. Вставьте эти файлы в ту папку, где лежит ваш скомпилированный файл `fractal_studio.exe`.
4. Готово! Запускайте `fractal_studio.exe` двойным кликом.

### 2. Как запустить на Linux (на примере Fedora / RedHat)

В Linux всё настраивается быстрее всего — буквально одной командой в терминале:

1. Устанавливаем графическую библиотеку SFML разработчика:
   ```bash
   sudo dnf install SFML-devel
   ```
   *(Если у вас Ubuntu, Linux Mint или Debian, то команда будет: `sudo apt install libsfml-dev`).*
2. Компилируем (собираем) наш исходный код в готовую программу:
   ```bash
   g++ main.cpp -o fractal_studio -lsfml-graphics -lsfml-window -lsfml-system
   ```
3. Запускаем получившееся приложение:
   ```bash
   ./fractal_studio
   ```

---

### 3. Как запустить на Apple macOS

На компьютерах Mac программа собирается через стандартный терминал:

1. Установите менеджер пакетов Homebrew (если его еще нет) и скачайте библиотеку SFML одной командой:
   ```bash
   brew install sfml
   ```
2. Скомпилируйте проект с помощью стандартного компилятора Clang, указав пути, куда Homebrew сохранил файлы:
   ```bash
   clang++ main.cpp -o fractal_studio -I/opt/homebrew/include -L/opt/homebrew/lib -lsfml-graphics -lsfml-window -lsfml-system
   ```
3. Запустите готовую программу:
   ```bash
   ./fractal_studio
   ```
